내 컴퓨터에 AI 고양이 펫 만들기

바탕화면 위에 복슬복슬 고양이가 살아요. 식빵 굽고, 살금살금 걷고, 먹이도 먹고, 말도 걸고 — 내가 시킨 작업이 끝나면 "다 됐다냥!" 하고 알려주기까지 해요. 다운로드해서 바로 쓰거나, 직접 만들 수도 있어요.

왼쪽 백이(흰 페르시안) · 오른쪽 깜이(러시안블루) — 실행할 때마다 랜덤으로 한 마리가 나와요
1
이 펫으로 뭘 할 수 있나요
🐾
살아있는 것처럼 움직여요
평소엔 식빵 굽기, 가끔 살금살금 기어가기·낮잠. 눈도 깜빡, 몸도 둥실둥실.
항상 화면 위에 떠 있고, 빈 곳은 클릭이 뒤로 통과돼서 작업에 방해 안 돼요
🍽️
쓰다듬고 먹이 주고 대화해요
쓰다듬으면 눈 감고 방긋, 먹이 주면 그릇에서 냠냠, 대화하면 인사·명언·스몰토크.
우클릭 메뉴에서 대화·먹이·쓰다듬기, 백이↔깜이 전환까지
🔔
작업이 끝나면 알려줘요 (Claude Code 연동)
다른 일 하는 동안 시켜둔 작업이 끝나거나 확인이 필요하면, 고양이가 말풍선으로 알려줘요. 여러 프로젝트를 동시에 돌려도 어떤 작업인지 이름표를 붙여서 구분해줘요.
이 알림 기능은 Claude Code를 쓸 때만 필요해요. 그냥 귀여운 펫으로만 써도 충분!
2
다운로드해서 바로 쓰기
⬇️ 펫 다운로드 (ClaudePet.exe)
1
받아서 더블클릭 — 끝!
위 버튼으로 ClaudePet.exe 를 받아 더블클릭하면 화면 오른쪽 아래에 고양이가 나와요. 설치도, 다른 프로그램도 필요 없어요.
처음 실행 때 ‘Windows의 PC 보호’ 창이 뜨면 추가 정보 → 실행 을 눌러주세요.
2
회사에서 .exe 가 막힐 때만
exe 다운로드가 막히면 → .bin 버전 을 받아 파일 이름 끝을 .bin → .exe 로 바꾸고 더블클릭하면 돼요.
확장자가 안 보이면: 파일 탐색기 상단 [보기] → [파일 확장명] 체크 후 이름 바꾸기.
3
조작법
먹이주기(그릇에서 냠냠) · 쓰다듬기(눈 감고 방긋)
1
이동 — 고양이를 마우스로 드래그
2
쓰다듬기 — 고양이 더블클릭
3
우클릭 메뉴 — 대화하기 · 먹이주기 · 크기 줄이기 · 백이만 / 깜이만 / 두마리 보기 · 펫 종료
4
부팅 시 자동 실행 — Win+R → shell:startup 폴더에 ClaudePet.exe 바로가기 넣기
🐾🐾 두 마리: 우클릭 → ‘두마리 보기’ 를 누르면 백이·깜이가 같이 나와요. 각자 따로 드래그해서 원하는 자리에 두면 돼요. (다시 한 마리로: ‘백이만 / 깜이만 보기’)
4
나만의 캐릭터로 바꾸기 (이름·그림·동작 전부)
파이썬 같은 거 필요 없어요. 핵심은 하나 — 파일 이름 앞부분이 그대로 캐릭터 이름이 돼요. 내 고양이 이름이 몽이라면 몽이_idle.png 처럼 저장하면 말풍선에 “몽이”로 뜨고 그 그림으로 움직여요.
1
AI로 캐릭터 그림 만들기
아무 이미지 생성 AI(ChatGPT, 힉스필드 등)로 원하는 캐릭터를 포즈별로 만들어요.
📸 사진은 이렇게 준비하세요:
① 배경 투명 PNG — 제일 중요! (AI에 “배경 투명하게”라고 요청하거나 remove.bg 같은 무료 사이트로 배경 지우기)
② 캐릭터 한 마리만 · 가운데 · 전신이 다 보이게
③ 발(바닥 닿는 부분)이 그림 맨 아래 — 바닥 그림자·글자는 빼기 (안 그러면 붕 떠 보여요)
④ 6장의 크기·비율을 비슷하게 — 그래야 포즈 바뀔 때 안 커졌다 작아졌다 해요
⑤ 먹이 포즈(_eat)만 밥그릇+먹이까지 같이 그리면 자연스러워요
※ 크기는 아무래도 괜찮아요(자동으로 맞춰줘요). 정사각형/세로 비율이면 무난.
2
‘내이름_동작.png’ 으로 저장
앞의 몽이 자리에 원하는 이름을 넣으면 돼요. (아래는 예시)
파일 이름이 동작에 쓰여요
몽이_idle.png평소 모습 — 이 한 장은 꼭 필요
몽이_sleep.png자는 모습
몽이_crawl.png걷는 / 기어가는 모습
몽이_react.png대화할 때 신난 표정
몽이_eat.png먹이주기 (그릇+먹이까지 그리면 예뻐요)
몽이_happy.png쓰다듬을 때 행복한 표정
idle 한 장만 있어도 동작해요(안 만든 포즈는 평소 모습으로 대체). 6장 다 만들면 완벽! 두 마리로 보고 싶으면 다른 이름으로 한 세트 더 만들면 돼요 (예: 코코_idle.png …).
3
exe 옆에 sprites 폴더 넣고 실행
ClaudePet.exe 와 같은 곳에 sprites 라는 폴더를 만들어 그 안에 내 이미지를 넣어요. → exe 더블클릭하면 내 캐릭터(내 이름)가 나와요!
